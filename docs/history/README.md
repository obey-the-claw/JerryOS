# Build history: the checkpoint guides

These are the step-by-step test guides written while JerryOS was being
built, one per checkpoint (Checkpoint 1, the firmware backup, is in
[backup/README.md](../../backup/README.md)). They're kept for the story and
for anyone curious how each part was tested; some details (menu names,
button hints, file names) have changed since.

**To use JerryOS today, read the [user guide](../USER-GUIDE.md).** The
whole build diary is in [BUILDLOG.md](../../BUILDLOG.md).
